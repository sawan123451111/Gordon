# ProductivityPro Landing Page

A clean, responsive landing page for a productivity tool.

## Features

- Fully responsive design (mobile, tablet, desktop)
- Modern gradient hero section with animated chart visualization
- Feature cards with hover effects
- Testimonial section
- Benefits section with dark theme
- Call-to-action sections
- Smooth animations

## Usage

Open `index.html` in any web browser to view the landing page.
