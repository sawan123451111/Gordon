# LY Visuals - Premium Video Ad Agency Website

A modern, professional website for LY Visuals, a premium video advertising agency.

## Features

- **Responsive Design** - Fully responsive layout that works on all devices
- **Modern UI** - Clean, professional design with smooth animations
- **Interactive Elements** - Mobile menu, testimonial slider, scroll animations
- **Contact Form** - Integrated contact form with validation
- **SEO Optimized** - Semantic HTML structure with meta tags

## Sections

1. **Hero** - Eye-catching hero section with animated background and statistics
2. **About** - Company introduction and key features
3. **Services** - Showcase of 6 main services offered
4. **Portfolio** - Grid display of featured projects
5. **Process** - 4-step workflow explanation
6. **Testimonials** - Auto-playing testimonial slider
7. **Contact** - Contact form and company information
8. **Footer** - Links, newsletter signup, and social media

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- Google Fonts (Inter, Playfair Display)

## Getting Started

Simply open `index.html` in a web browser to view the website.

```bash
# Using Python's built-in server
python -m http.server 8000

# Using Node.js http-server
npx http-server
```

Then visit `http://localhost:8000` in your browser.
